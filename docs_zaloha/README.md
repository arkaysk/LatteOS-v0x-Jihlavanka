# docs_zaloha — archív dokumentov

o stave, staré merania a snímky. Pravidlá:

- názov začína **dátumom stavu**, ktorý dokument opisuje: `RRRR-MM-DD-meno.md` (priečinok so snímkami tiež);
- **obsah ostáva starý** — neopravuje sa podľa dnešného stavu; navrch sa smie doplniť poznámka (odkiaľ dokument je,
  čo dnes platí namiesto neho, kde sú súbory, na ktoré odkazuje);
- odkazy z platnej dokumentácie smerujú sem iba na históriu („ako to bolo“, merania), nikdy ako na platný stav.
