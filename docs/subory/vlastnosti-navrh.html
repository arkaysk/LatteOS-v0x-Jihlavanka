Čo je odkiaľ:
  • Windows 11: záložky Všeobecné, Zabezpečenie, Podrobnosti, Predchádzajúce verzie, Odkaz; veľkosť aj na disku; tri dátumy s „pred 57 minútami“; OK · Zrušiť · Použiť; „Odstrániť osobné údaje“.
